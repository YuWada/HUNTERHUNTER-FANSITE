# ハンターハンター アドベンチャーゲーム用 セリフ・名言リスト

モモゼの念獣の「おヒマ？」から始まる、全編ハンターハンターのセリフで構成される選択肢型アドベンチャーゲームのためのセリフ集です。

## 1. 導入・質問・NPCのセリフ（問いかけ）
ゲームの進行や、プレイヤーに対するアクションとして使えるセリフです。

* **「おヒマ？」**（モモゼ＝ホイコーロの念獣）
* **「おヒマが出来たら教えて？ね？ね？」**（モモゼの念獣：断られた時や無視された時の再度の問いかけ）
* **「1.息子 2.娘 どちらかしか助けられない どちらを助ける？」**（ドキドキ2択クイズのおばば）
* **「クセになってんだ 音殺して動くの」**（キルア：背後を取られた時などのイベント）
* **「キミの敗因は容量（メモリ）のムダ使い❤︎」**（ヒソカ：プレイヤーが間違った選択をしてゲームオーバーになる時）
* **「そりゃ悪手だろ」**（ネテロ：プレイヤーが微妙な選択肢を選んだ時のツッコミ）
* **「祈りとは 心の所作」**（ネテロ：セーブポイントや回復ポイントでのセリフ）
* **「オレでなきゃ見逃しちゃうね」**（団長の手刀を見逃さなかった人：素早いイベントが起きた時）
* **「道草を楽しめ 大いにな」**（ジン：エンディングや寄り道ルートに入った時）

## 2. プレイヤーの回答・選択肢
プレイヤーが選ぶアクションや返答として使えるセリフです。

* **「いや…ヒマではない…」**（ヒマ？に対する拒否の選択肢）
* **「ヒマだったから…」**（ヒマ？に対する肯定の選択肢）
* **「沈黙！」**（ドキドキ2択クイズの正答、または無視してやり過ごす選択肢）
* **「右！」「左！」**（分かれ道などでのシンプルな選択）
* **「両方！！」**（無茶な選択肢を選ぶ時）
* **「俺が3人分になる」**（ゴレイヌ：数的不利な状況や、タスクが多い時）
* **「もうこれで終わってもいい。だからありったけを」**（ゴン：捨て身の攻撃や、ラストバトルの選択肢）
* **「感謝するぜ お前と出会えた これまでの全てに!!!」**（ネテロ：強敵との遭遇や、感謝を伝える選択肢）
* **「死後強まる念…!!」**（ゲームオーバー時や、倒した敵が復活した時など）
* **「だます方が悪いに決まっている」**（クラピカ：NPCに騙された時の反論）
* **「品性は金で買えないよ」**（レオリオ：お金を要求された時や、下品な敵に対する煽り）
* **「オレはいいけど、ヤツはどうかな？」**（ヒソカ：仲間に戦闘を任せる時）
* **「あいつワシより強くね？」**（ネテロ：強敵から逃げるための理由付け選択肢）
* **「ボマー捕まえた」**（ゴン：敵を捕獲した時）

## 3. 会話の流れのアイデア（モモゼの念獣ルート）
**NPC（念獣）:** 「おヒマ？」

**選択肢:**
1. 「ヒマだったから…」 → 取り憑かれてゲームオーバー（「キミの敗因は容量（メモリ）のムダ使い❤︎」）
2. 「いや…ヒマではない…」 → 次へ
3. 「沈黙！」 → 次へ

**NPC（念獣）:** 「おヒマが出来たら教えて？ね？ね？」

**選択肢:**
1. 「俺が3人分になる」（忙しさをアピールして回避を試みる）
2. 「そりゃ悪手だろ」（しつこい念獣にツッコミを入れる）
3. 「もうこれで終わってもいい。だからありったけを」（念獣とのバトルに突入）
