# 非公開作業フォルダ

このフォルダはGitで管理しますが、Cloudflare PagesのWeb公開対象には含めません。企画資料、下書き、作業メモなどを配置できます。

注意：GitHubリポジトリ自体はPublicです。このフォルダの内容もGitHub上では閲覧できるため、秘密情報、個人情報、APIキーなどは保存しないでください。

## フォルダ構成

- `HUNTER_DATA/` — 神眼データベースの原稿・生成元データ
- `HUNTER_KEISAI/` — ジャンプ掲載号リストの原稿・作業資料
  - `scripts/` — 掲載号リスト専用の取得・変換・HTML生成スクリプト
- `HUNTER_MEIGEN/` — 名台詞集の原稿・生成・修正スクリプト
- `HUNTER_MOJI/` — 文字・表記に関する作業資料
- `SITE_TOOLS/legacy/` — 現在は使っていない旧サイト共通ツールの保管場所

サイト全体に共通するヘッダーとGA4の登録処理だけは、プロジェクト直下の `inject_shared_header.py` で管理します。
