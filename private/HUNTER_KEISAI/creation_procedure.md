# HUNTER×HUNTER ジャンプ掲載一覧の作成手順

この一覧表は以下の手順で作成されました。

1. **データソースの取得**:
   - URL: `https://www.jajanken.net/sakuhins/b9anmLwOAR` (ジャジャン研 - HUNTER×HUNTER)
   - ツールを用いて上記URLのHTMLコンテンツを取得しました。

2. **HTMLの解析 (スクレイピング)**:
   - Pythonの標準ライブラリである `html.parser` を使用して、カスタムパーサー (`JajankenParser`) を作成しました。
   - `<tr>` ごとにテーブルの行を処理し、`<td>` タグ内の各種データ（掲載号、リンク、タイトル、順位）を抽出しました。
   - 発売日については、掲載号のリンクURL (`/issues/YYYY-MM-DD/`) から日付部分を抽出しました。
   - 備考情報（新連載、巻頭カラー、休載など）については、タイトルの前にある `<span class="chapter-pill">` などのタグから抽出しました。

3. **コミックス巻数の算出**:
   - 抽出した各話のタイトル（例: `No.001 出発の日`）から話数（番号）を正規表現で抽出しました。
   - 一般的な「HUNTER×HUNTER」の各巻の収録話数パターン（1巻は1-8話、以降は基本的に9-10話ずつなど）に基づいて、話数から収録巻数を決定するロジック（マッピング関数）を作成し、それぞれに「何巻」という情報を付与しました。
   - 休載などの場合は、タイトルに番号が含まれていないため「-」と表示するようにしました。

4. **Markdownファイルの生成**:
   - 抽出・加工したデータ（掲載号、発売日、タイトル、コミックス、備考）をまとめ、Markdownのテーブル形式にフォーマットして出力しました。

上記処理を行うスクリプトにより自動生成しています。
