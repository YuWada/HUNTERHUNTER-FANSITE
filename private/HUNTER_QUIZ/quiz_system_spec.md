# HUNTER試験ドキドキ５択クイズ アプリケーション仕様書

## 1. 概要
「HUNTER試験ドキドキ５択クイズ」をWebブラウザ上で動作するJavaScriptアプリケーションとして実装する。全25問を出題し、ユーザーの正答状況に応じて難易度が段階的に上昇するシステムを採用する。

## 2. 動作環境
- フロントエンド：HTML / CSS / Vanilla JavaScript
- サーバーサイド：なし（静的ファイルとしてブラウザ上で完結）
- 配置先：`/Users/yu/Antigravity_workspace/HUNTERHUNTER-FANSITE/public/hunterquiz`

## 3. クイズデータの管理と難読化
- クイズの元データは `hunter_quiz_ver20260830_1.md` からCSV形式に変換する。
- ユーザーに問題の答えをソースコードやネットワークタブから直接読み取られないようにするため、CSVデータを難読化（Base64エンコード＋簡易暗号化など）した状態で public 側に配置する。
- アプリケーション起動時にJavaScript側で難読化データを復号・パースし、クイズデータとしてメモリに読み込む。

## 4. 出題システム（段階式）
全10段階の難易度が設定されており、段階1からスタートする。
1つの段階につき「5問」ランダムに出題される。これを計5セット（合計25問）行う。

### 4.1. 段階ごとの出題レベル
- 段階1：レベル1〜2
- 段階2：レベル1〜2
- 段階3：レベル2〜3
- 段階4：レベル2〜3
- 段階5：レベル3〜4
- 段階6：レベル3〜4
- 段階7：レベル3〜5
- 段階8：レベル3〜5
- 段階9：レベル4〜5
- 段階10：レベル4〜5（※要確認事項）

### 4.2. 難易度の上昇ルール
- 1つの段階（5問）が終了した際、**5問すべて正解**していた場合は**「2段階」**次に進む（例：段階1→段階3）。
- 5問全問正解でなかった場合は**「1段階」**次に進む（例：段階1→段階2）。
- 正解・不正解にかかわらず、累計25問回答した時点で終了となる。
- パーフェクトルート：段階1 → 段階3 → 段階5 → 段階7 → 段階9 （計25問）

### 4.3. UI / UXの仕様
- **選択肢のランダム化**：5択の選択肢は毎回ランダムに並び替えられる。
- **後戻り不可**：一度回答すると前の問題に戻ることはできない。ブラウザの「戻る」操作への対策や、画面遷移を使わない単一ページ（SPA）での制御を行う。
- **フィードバックの非表示**：回答直後に「正解/不正解」は表示しない。25問すべての回答が終わった後に一括して結果を表示する。

## 5. 得点とランク付け
### 5.1. 得点計算
- 得点は「正解した問題が出題された段階の数字」が加点される。
  （例：段階1で正解＝1点、段階9で正解＝9点）
- 最大得点は 125点 となる。
  （パーフェクト時：段階1(5点)＋段階3(15点)＋段階5(25点)＋段階7(35点)＋段階9(45点)＝125点）

### 5.2. ランク
獲得した得点に応じて、以下のランクを付与する。
- 125点：トリプルハンター
- 120点以上：ダブルハンター
- 110点以上：シングルハンター
- 100点以上：プロハンター
- 85点以上：新人ハンター
- 60点以上：ハンター試験三次試験レベル
- 30点以上：ハンター試験新人受験者レベル
- 30点未満：一般人レベル

## 6. リザルト画面
- **表示内容**：「N問中M問正解」、得点、ランク。
- **豪華な演出**：上位ランク（トリプルハンターなど）になるほど、結果画面の見た目（エフェクトや装飾）を豪華にする。
- **シェア機能**：X（旧Twitter）への結果ツイートボタン、結果テキストのクリップボードコピーボタンを設置（水見式アプリの仕様を踏襲）。
- **リトライ機能**：「問題はランダムに出題される。来年もまた受験しよう！！」というメッセージと共に、最初からやり直せるボタンを設置する。
