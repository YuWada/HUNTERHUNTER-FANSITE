# HUNTER×HUNTER 神眼（ゴッドアイ）データベース メンテナンスガイド

本データベースは、プレーンなテキストファイル（Markdown/OKF形式）でナレッジグラフを構築し、静的サイトジェネレーター（MkDocs）で公開用HTMLへと変換する特殊な運用を行っています。

## 1. 徹底した「マスターデータ絶対主義」のルール（重要）

本プロジェクトは、安全なデータ管理とクリーンな公開サイト作成のため、**「作業用（private）」と「公開用（public）」の完全分離**を行っています。

### ⚠️ 絶対にやってはいけないこと
**`public/hunterdata/` 内のHTMLファイルやCSSファイルを、手動で直接編集しないでください。**
公開用フォルダは、あくまで「プログラムが出力した一時的な結果」です。直接編集しても、次にビルドした際にすべて上書きされて消滅します。

### ✅ 正しいワークフロー
データの追加や修正を行う場合は、必ず以下の手順を守ってください。

1. **マスターデータ（OKF形式）の編集**
   `private/HUNTER_DATA/` フォルダ内にある各カテゴリ（登場人物、用語集、念能力など）の `.md` ファイルを編集・追加します。
2. **自動ビルドスクリプトの実行**
   ターミナルで `private/HUNTER_DATA/` に移動し、`./build_site.sh` を実行します。
3. **HTMLの自動生成**
   システムが Markdown を読み込み、デザインを適用して、`public/hunterdata/` へ最新のHTMLを一括出力（上書き）します。

## 2. ディレクトリ構成の役割

*   📁 **`private/HUNTER_DATA/` (マスター環境)**
    *   原稿データ（Markdown）や、自動化スクリプト、管理用メモを保管する**非公開の作業場所**です。
*   📁 **`public/hunterdata/` (公開用環境)**
    *   ビルドツールによって生成された**公開用の静的HTMLファイル**が出力される場所です。
    *   このフォルダの中身をそのままCloudflare Pages等にデプロイすることで、全世界にサイトが公開されます。内部管理用のファイルはここには出力されません。

## 3. データの追加ルールと「オートリンカー」

新しい用語、キャラクター、念能力のページを追加したり、既存の文章を編集する際は、**「他のページへのリンク（パス）を自力で書く必要はありません」**。

テキストを入力する際は、常にプレーンテキストとして自然に文章を書いてください。
ビルド時に自動実行される「オートリンカー機能」が、データベース内の全ての用語を照合し、全自動で相互リンクを張り巡らせます（例：「バンジーガム」と書くだけで自動的に念能力ページへリンクされます）。

※注：文脈の破壊を防ぐため、「絶」などの1文字の単語や、カタカナ単語の一部（「ギドン」の中の「ギド」など）は自動的にリンク対象外となるよう高度なAI判定が組み込まれています。

## 4. ビルドスクリプト（build_site.sh）がやっていること

1. **オートリンカーの実行**: 全てのファイルをスキャンし、存在する用語を自動的にリンク化します。
2. **ナビゲーションと掲載数の動的生成**: 登録されているキャラクター数やカード枚数をカウントし、トップページの目次に動的に埋め込みます。
3. **クリーンなビルド準備**: 管理用ファイルを自動的に除外します。
4. **MkDocsの実行**: 抽出された原稿データのみを美しい静的HTML（Materialテーマ・カスタムアイコン適用）にコンパイルし、公開フォルダへと出力します。

この仕組みにより、管理者はHTMLや複雑なリンク構造を一切気にすることなく、ただテキストを書き続けるだけで高度なデータベースサイトを運営することが可能です。

## 5. ネットワークグラフの更新手順

マスターデータ（`.md`）を追加・編集したあとは、データベースの全体像を可視化する「ネットワークグラフ（神眼データベースの小宇宙）」も以下の手順で手動更新してください。

1. **グラフ生成スクリプトの実行**
   ターミナルで `private/HUNTER_DATA/` に移動し、以下のコマンドを実行します。
   ```bash
   python3 generate_graph.py
   ```
   ※ これにより `public/hunterdataglaph/index.html` が生成（上書き）されます。

2. **共通ヘッダーの適用（インジェクション）**
   生成されたグラフのページに、サイト共通のヘッダーナビゲーションを適用するために、プロジェクトルートにあるヘッダー追加ツールを実行します。
   ```bash
   cd ../../  # プロジェクトのルートディレクトリに移動
   python3 inject_shared_header.py
   ```
   ※ このコマンドを実行すると、`public/` 内のすべてのHTMLファイル（先ほど生成したグラフHTMLを含む）をスキャンし、ヘッダータグが未挿入のものにだけ自動で追記してくれます。

以上の手順により、最新のデータが反映されたネットワークグラフが公開用フォルダに準備されます。
