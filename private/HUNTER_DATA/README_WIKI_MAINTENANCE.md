# HUNTER×HUNTER Wiki メンテナンスガイド

このWiki（データベース）は、プレーンなテキストファイル（Markdown/OKF形式）でナレッジグラフを構築し、静的サイトジェネレーター（MkDocs）で公開用HTMLへと変換する特殊な運用を行っています。

## 1. ディレクトリ構成の考え方

本プロジェクトは、安全なデータ管理とクリーンな公開サイト作成のため、**「作業用（private）」と「公開用（public）」の完全分離**を行っています。

*   📁 **`private/HUNTER_DATA/` (現在のフォルダ)**
    *   原稿データ（Markdown）や、自動化スクリプト、管理用メモ（『検討中キーワード.md』など）を保管する**非公開の作業場所**です。
    *   執筆や修正はすべてこの中のファイルで行います。
*   📁 **`public/hunterdata/`**
    *   ビルドツールによって生成された**公開用の静的HTMLファイル**が出力される場所です。
    *   このフォルダの中身をそのままCloudflare Pages等にデプロイ（アップロード）することで、全世界にサイトが公開されます。内部管理用のファイルはここには一切出力されません。

## 2. データの追加ルール（プレーンテキスト・ファースト）

新しい用語、キャラクター、念能力のページを追加したり、既存の文章を編集する際は、**「他のページへのリンク（パス）を自力で書く必要はありません」**。

*   **悪い例**: `クラピカは[幻影旅団](../用語集/幻影旅団.md)への復讐のために…`
*   **良い例**: `クラピカは幻影旅団への復讐のために…`

テキストを入力する際は、常にプレーンテキストとして自然に文章を書いてください。リンク付けはすべて後述の「オートリンカー」が全自動で行います。
※注：「絶」や「円」など、1文字の単語は文章が読みにくくなるのを防ぐため自動リンクの対象外としています。

## 3. サイトのビルド（リンク生成 ＆ HTML出力）

データを書き終えたら、当ディレクトリ直下にある `build_site.sh` を実行するだけで、「全ファイルの自動リンク化」と「公開用HTMLのビルド」が一括で行われます。

### 実行方法
ターミナルを開き、このディレクトリ（`private/HUNTER_DATA`）内で以下のコマンドを実行します。

```bash
./build_site.sh
```

### ビルドスクリプト（build_site.sh）がやっていること
1. **オートリンカーの実行**: 全てのファイルをスキャンし、存在する用語を自動的にリンク化（Markdownリンク化）します。過去の1文字リンクなども自動で解除します。
2. **クリーンなビルド準備**: 『検討中キーワード.md』やこのREADMEなど、公開すべきではない管理用ファイルを自動的に除外します。
3. **MkDocsの実行**: 抽出された原稿データのみを美しい静的HTML（Materialテーマ）にコンパイルし、`../../../public/hunterdata` フォルダへと出力します。

この仕組みにより、管理者はHTMLや複雑なリンク構造を一切気にすることなく、ただテキストを書き続けるだけで高度なWikiサイトを運営することが可能です。
