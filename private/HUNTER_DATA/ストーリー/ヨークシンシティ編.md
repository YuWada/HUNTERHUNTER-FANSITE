# ヨークシンシティ編

## あらすじ（詳細版）
9月1日、世界最大のオークションが開催される大都市ヨークシンシティに集結した[ゴン＝フリークス](../登場人物/ゴン＝フリークス.md)、[キルア＝ゾルディック](../登場人物/キルア＝ゾルディック.md)、[レオリオ＝パラディナイト](../登場人物/レオリオ＝パラディナイト.md)、[クラピカ](../登場人物/クラピカ.md)の4人。ゴンとキルアは高額なハンター専用ゲーム「[グリードアイランド](../用語集/用語集_グリードアイランド編/グリードアイランド.md)」の入手を目的とし、[クラピカ](../登場人物/クラピカ.md)は人体収集家に奪われた同胞（[クルタ族](../用語集/用語集_ヨークシンシティ編/クルタ族.md)）の「緋の眼」を取り戻すため、マフィアのボディガードとしてこの街を訪れていた。
一方、[クラピカ](../登場人物/クラピカ.md)の同胞を皆殺しにした盗賊集団「[幻影旅団](../用語集/用語集_ヨークシンシティ編/幻影旅団.md)（クモ）」の団長[クロロ＝ルシルフル](../登場人物/クロロ＝ルシルフル.md)も、オークションのお宝をすべて奪うために全団員をヨークシンに招集していた。

旅団は[マフィアンコミュニティー](../用語集/用語集_ヨークシンシティ編/マフィアンコミュニティー.md)が主催する[地下競売](../用語集/用語集_ヨークシンシティ編/地下競売.md)を襲撃するが、お宝はすでにマフィア最強の武闘派集団「[陰獣](../用語集/用語集_ヨークシンシティ編/陰獣.md)」の「梟」によって移動された後だった。荒野へと移動した旅団をマフィアたちが取り囲むが、[ウボォーギン](../登場人物/ウボォーギン.md)が単独で[陰獣](../用語集/用語集_ヨークシンシティ編/陰獣.md)4人を全滅させるという圧倒的な力を見せつける。
その隙を突き、[クラピカ](../登場人物/クラピカ.md)は復讐のために編み出した[念能力](../用語集/用語集_念/念能力.md)「[束縛する中指の鎖（チェーンジェイル）](../念能力/束縛する中指の鎖（チェーンジェイル）.md)」で[ウボォーギン](../登場人物/ウボォーギン.md)を捕獲する。後日行われた1対1の決闘において、[クラピカ](../登場人物/クラピカ.md)は緋の眼発動時に全系統の能力を100%引き出せる「[絶対時間（エンペラータイム）](../用語集/用語集_念/絶対時間（エンペラータイム）.md)」を発動し、旅団一の怪力を誇る[ウボォーギン](../登場人物/ウボォーギン.md)を完全に打ち倒す。

仲間の死に激怒した[幻影旅団](../用語集/用語集_ヨークシンシティ編/幻影旅団.md)は、クロロの指揮のもとヨークシンシティでマフィアに対する大虐殺（鎮魂歌・レクイエム）を引き起こす。マフィアを束ねる[十老頭](../用語集/用語集_ヨークシンシティ編/十老頭.md)は、プロの殺し屋である[シルバ＝ゾルディック](../登場人物/シルバ＝ゾルディック.md)や[ゼノ＝ゾルディック](../登場人物/ゼノ＝ゾルディック.md)を雇ってクロロを追い詰める。凄まじい死闘が繰り広げられるが、クロロがあらかじめ[イルミ＝ゾルディック](../登場人物/イルミ＝ゾルディック.md)を雇い[十老頭](../用語集/用語集_ヨークシンシティ編/十老頭.md)を暗殺させていたため、依頼主不在により戦闘は中断される。
旅団は死体のダミーを用意して自分たちの死亡を偽装し、街から去るかに見えた。しかし、ゴンとキルア、[クラピカ](../登場人物/クラピカ.md)は彼らが生きていることを見抜き、死の危険が伴う追跡劇を再開する。

[パクノダ](../登場人物/パクノダ.md)の記憶読み取り能力により、[クラピカ](../登場人物/クラピカ.md)の秘密と居場所がバレそうになる絶体絶命の状況下、[クラピカ](../登場人物/クラピカ.md)達はクロロを暗闇に乗じて拉致することに成功する。息詰まる人質交換の末、[クラピカ](../登場人物/クラピカ.md)はクロロの心臓に「[律する小指の鎖（ジャッジメントチェーン）](../念能力/律する小指の鎖（ジャッジメントチェーン）.md)」を打ち込み、[念能力](../用語集/用語集_念/念能力.md)の使用と団員との接触を永遠に禁じる。[パクノダ](../登場人物/パクノダ.md)も自身の命を引き換えに[クラピカ](../登場人物/クラピカ.md)の情報を団員に撃ち込み死亡。旅団は団長を失ったまま街を去り、[クラピカ](../登場人物/クラピカ.md)の復讐劇は「クロロの[除念](../用語集/用語集_念/除念.md)師探し」という新たな展開を残して一時的な休戦へと移行する。
