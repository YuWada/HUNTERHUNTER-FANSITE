# ヨークシンシティ編

## あらすじ（詳細版）
9月1日、世界最大のオークションが開催されるヨークシンシティに集結した[ゴン＝フリークス](../登場人物/ゴン＝フリークス.md)、[キルア＝ゾルディック](../登場人物/キルア＝ゾルディック.md)、[レオリオ＝パラディナイト](../登場人物/レオリオ＝パラディナイト.md)、[クラピカ](../登場人物/クラピカ.md)の4人。
一方、[クラピカ](../登場人物/クラピカ.md)の同胞（[クルタ族](../用語集/用語集_ヨークシンシティ編/クルタ族.md)）を皆殺しにした盗賊集団「[幻影旅団](../用語集/用語集_ヨークシンシティ編/幻影旅団.md)（クモ）」の団長[クロロ＝ルシルフル](../登場人物/クロロ＝ルシルフル.md)も、オークションのお宝をすべて奪うために全団員を招集していた。

[マフィアンコミュニティー](../用語集/用語集_ヨークシンシティ編/マフィアンコミュニティー.md)が主催する[地下競売](../用語集/用語集_ヨークシンシティ編/地下競売.md)を襲撃した旅団だが、お宝はすでに[陰獣](../用語集/用語集_ヨークシンシティ編/陰獣.md)の「梟」によって移動された後だった。荒野で[ウボォーギン](../登場人物/ウボォーギン.md)が[陰獣](../用語集/用語集_ヨークシンシティ編/陰獣.md)4人を単独で全滅させる圧倒的な力を見せつける中、マフィアのボディガードとして潜入していた[クラピカ](../登場人物/クラピカ.md)が「[束縛する中指の鎖（チェーンジェイル）](../念能力/束縛する中指の鎖（チェーンジェイル）.md)」で[ウボォーギン](../登場人物/ウボォーギン.md)を捕獲する。
後日、1対1の決闘において、[クラピカ](../登場人物/クラピカ.md)は「[絶対時間（エンペラータイム）](../用語集/用語集_念/絶対時間（エンペラータイム）.md)」を発動し、[ウボォーギン](../登場人物/ウボォーギン.md)を撃破する。

報復に燃える[幻影旅団](../用語集/用語集_ヨークシンシティ編/幻影旅団.md)は、[クロロ＝ルシルフル](../登場人物/クロロ＝ルシルフル.md)の指揮のもとヨークシンシティで大虐殺（鎮魂歌・レクイエム）を引き起こす。[十老頭](../用語集/用語集_ヨークシンシティ編/十老頭.md)はプロの殺し屋（[シルバ＝ゾルディック](../登場人物/シルバ＝ゾルディック.md)や[ゼノ＝ゾルディック](../登場人物/ゼノ＝ゾルディック.md)）を雇って[クロロ＝ルシルフル](../登場人物/クロロ＝ルシルフル.md)を追い詰めるが、[クロロ＝ルシルフル](../登場人物/クロロ＝ルシルフル.md)は[イルミ＝ゾルディック](../登場人物/イルミ＝ゾルディック.md)を雇い[十老頭](../用語集/用語集_ヨークシンシティ編/十老頭.md)を暗殺させていたため戦闘は中断される。
旅団は死体のダミーを用意して死亡を偽装するが、[ゴン＝フリークス](../登場人物/ゴン＝フリークス.md)と[キルア＝ゾルディック](../登場人物/キルア＝ゾルディック.md)、[クラピカ](../登場人物/クラピカ.md)は彼らが生きていることを見抜き、追跡を再開。[パクノダ](../登場人物/パクノダ.md)の記憶読み取り能力により[クラピカ](../登場人物/クラピカ.md)の秘密がバレそうになる絶体絶命の状況下で、[クラピカ](../登場人物/クラピカ.md)は[クロロ＝ルシルフル](../登場人物/クロロ＝ルシルフル.md)を暗闇に乗じて拉致することに成功する。

人質交換の末、[クラピカ](../登場人物/クラピカ.md)は[クロロ＝ルシルフル](../登場人物/クロロ＝ルシルフル.md)の心臓に「[律する小指の鎖（ジャッジメントチェーン）](../念能力/律する小指の鎖（ジャッジメントチェーン）.md)」を打ち込み、[念能力](../用語集/用語集_念/念能力.md)の使用と団員との接触を禁じる。[パクノダ](../登場人物/パクノダ.md)も自身の命を引き換えに[クラピカ](../登場人物/クラピカ.md)の情報を団員に撃ち込み死亡。旅団は団長を失ったまま街を去り、[クラピカ](../登場人物/クラピカ.md)の復讐劇は一時的な休戦（[除念](../用語集/用語集_念/除念.md)師探しの物語）へと移行する。
