# 偽試験官

## 略歴・人物像
声 - 加勢田進 / 金光宣明
[ヌメーレ湿原](../用語集/用語集_ハンター試験編/ヌメーレ湿原.md)に住む魔獣の一種・人面猿で、正確には部外者。第一次試験の中盤で[サトツ](サトツ.md)に似た別の人面猿を引き連れ、[サトツ](サトツ.md)を偽者と告発し、受験者を騙して連れ出そうとした。[ヒソカ＝モロウ](ヒソカ＝モロウ.md)がどちらが本物かを見破る実験で、[サトツ](サトツ.md)は[ヒソカ＝モロウ](ヒソカ＝モロウ.md)のトランプを受け止めるが、彼はそのまま死亡してしまう。徒党を組んでいた[サトツ](サトツ.md)似の人面猿は、原作と第1作では逃走を図ろうとした所を[ヒソカ＝モロウ](ヒソカ＝モロウ.md)に殺されるが、第2作ではそのまま逃げ伸びている。
