# アスタ

## 略歴・人物像
声 - 陰山真寿美 / 豊嶋真千子
アスタ組のリーダー。やたらとキルアをガキ扱いをする実力派の女性プレイヤー。仲間に'''アマナ'''（声 - 永吉由佳 / 戸田めぐみ：髪で顔左を[隠](../用語集/用語集_念/隠.md)した女性）と'''マンヘイム'''（声 - 不明 / 坂熊孝彦）がいる。カード「一坪の海岸線」を求めている。[カヅスール](カヅスール.md)の呼びかけで集まり[レイザー](レイザー.md)のイベントに参加する。その後、[ゲンスルー](ゲンスルー.md)に始末される。
