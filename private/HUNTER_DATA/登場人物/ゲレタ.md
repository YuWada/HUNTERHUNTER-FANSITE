# ゲレタ

## 略歴・人物像
声 - 松山鷹志 / 金光宣明
受験番号384番。ゴーグルと黒い肌が特徴の猟師。第四次試験でゴンのプレートを狙い尾行し、筋弛緩性の吹き矢毒でプレートを奪うが、自身もヒソカのターゲットだったため殺害され、プレートを奪われた。原作では彼の生首がゴンの元へ持ち込まれるシーンがあるが、アニメ版では第1作・第2作ともに別の描写に変更された。
