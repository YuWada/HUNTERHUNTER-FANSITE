# メンチ

## 略歴・人物像
声 - 日比野朱里 / 平野綾
一ツ星ハンター。美食ハンター。第二次試験官の1人。髪の色は第1作ではピンク、第2作ではエメラルドグリーン。
21歳ながら食文化への貢献が認められ、一ツ星の称号を持つ女性ハンター。一度食べたものの味は忘れない。短気で食に対するプライドが高く、キレると殊更に融通が利かなくなる。二次試験後半の課題は鮨で、「料理を通して観察力や注意力を図るテスト」だったのだが、[ハンゾー](ハンゾー.md)が鮨の作り方を思わずばらしてしまい、さらに鮨を軽んじる発言に激怒して美食審査の様相を呈してしまい、合格者0の事態を招く。横柄な態度を取っていたが[アイザック＝ネテロ](アイザック＝ネテロ.md)の仲裁によって自身の不備を認め、「クモワシのゆで卵」を課題とする再試験が行われた。劇中での[念の系統](../用語集/用語集_念/念の系統.md)は不明だが『幻の[グリードアイランド](../用語集/用語集_グリードアイランド編/グリードアイランド.md)』では[放出系](../用語集/用語集_念/放出系.md)の能力者として登場した。
アニメ第2作では、[ブハラ](ブハラ.md)と2人で1つの課題で豚を使った料理とされ、寿司試験パートがカットされたため、出番が大幅に減っている。
