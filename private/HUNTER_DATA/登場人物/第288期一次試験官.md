# 第288期一次試験官

## 略歴・人物像
声 - 乃村健次 / 伊藤栄次
[プロハンター](../用語集/用語集_ハンター試験編/プロハンター.md)。名称不明。第288期[ハンター試験](../用語集/用語集_ハンター試験編/ハンター試験.md)の1次試験を担当した。
「強い者にしかハンターは務まらない」という信条の持ち主で、その年の受験者が1489人と多く人数を絞る必要もあり、「2時間以内に他の受験者を5人倒してプレートを奪い、自分の所に持ってくる」という試験内容を考案・実施したところ、[キルア＝ゾルディック](キルア＝ゾルディック.md)の一人勝ちに終わってしまい、[アイザック＝ネテロ](アイザック＝ネテロ.md)の指示もあって否応なしに彼に[ハンター試験](../用語集/用語集_ハンター試験編/ハンター試験.md)合格を言い渡した。
