# クロロ＝ルシルフル

## 略歴・人物像
盗賊集団[幻影旅団](../用語集/幻影旅団.md)の団長（クモの頭）。[流星街](../用語集/用語集_ヨークシンシティ編/流星街.md)出身。
額に十字架のタトゥー、背中に逆十字が描かれたコートを着用している（変装時はオールバックを下ろし、普通の青年のように振る舞う）。
冷酷非情でありながら、団員を家族のように大切に想い、自身の命よりも旅団の存続を優先する。
高い知力と戦闘力を持ち、[ゾルディック家](../用語集/用語集_ゾルディック家編/ゾルディック家.md)のゼノ・シルバ2人を同時に相手にしても生き延びるほどの実力者。

## 念能力・特殊能力
**[特質系](../用語集/用語集_念/特質系.md)能力者**。他人の[念能力](../用語集/用語集_念/念能力.md)を盗み、自分のものとして使用することができる。

### 盗賊の極意（スキルハンター）
具現化した本（盗賊の極意）に他人の[念能力](../用語集/用語集_念/念能力.md)を封じ込め、使用できる能力。
盗むためには以下の厳しい条件をすべてクリアする必要がある。
1. 相手の[念能力](../用語集/用語集_念/念能力.md)を実際に見る。
2. 相手に念について質問し、相手がそれに答える。
3. 本の表紙にある手形と相手の手のひらを合わせる。
4. 1〜3を1時間以内に行う。

使用時は本を右手に持ち、使いたい能力のページを開いておく必要がある（対象が死ぬとページは消滅する）。

### 栞のテーマ（ダブルフェイス）
クロロがヒソカ戦に備えて追加した能力。本に「栞」を挟むことで、本を閉じても（両手を空けた状態でも）そのページの能力を使えるようになり、さらに別のページを開いて2つの能力を併用することが可能になった。
