# 審判

## 略歴・人物像
声 - 松山鷹志 / 河相智哉
複数存在し、それぞれで好みやスタンスが微妙に違うらしい。実際のダメージ量を重視してポイントを付ける審判もいれば、相手の裏をかく戦術などを評価してポイントを付ける審判もいる。
[ゴン＝フリークス](ゴン＝フリークス.md)と[ヒソカ＝モロウ](ヒソカ＝モロウ.md)の試合では、試合内容が危険な方向にエスカレートするのを防ぐため攻撃の有効ポイント判定の採点基準を下げるテクニカルジャッジで試合を早々に終わらせた。
