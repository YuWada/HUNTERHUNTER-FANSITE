# 200階クラスの案内係

## 略歴・人物像
声 - 甲斐田ゆき / 相橋愛子
垂れ目と物静かな口調が特徴のミステリアスな女性スタッフ。ヒソカがゴンとキルアを挑発する際に出した[オーラ](../用語集/用語集_念/オーラ.md)の存在には気付かなかった。ゴンとキルアが闘技場を去る際、悪戯で帽子を飛ばされている。なお、他にもエレベーターガール（声 - 前川優子〈第1作〉 / 久保ユリカ〈第2作〉）や、[フロアマスター](../用語集/用語集_天空闘技場編/フロアマスター.md)を詳しく説明する受付嬢（声 - 寺崎裕香〈第2作〉）もいた。
