# ゼホ

## 略歴・人物像
声 - 竹本英史 / 岡林史泰
[ハンゼ](ハンゼ.md)組。[強化系](../用語集/用語集_念/強化系.md)能力者。[カヅスール](カヅスール.md)の呼びかけで集まり[レイザー](レイザー.md)のイベントに参加する。力には自信があるようで酒場で[ボポボ](ボポボ.md)と相撲勝負をするも、キルアからは「完全に修行不足」「念無しの自分でも楽勝」と内心酷評される。実際にキルアの見立て通り、ただ立っているだけの[ボポボ](ボポボ.md)を全く動かせない有様だった。その後、[ゲンスルー](ゲンスルー.md)に始末される。
