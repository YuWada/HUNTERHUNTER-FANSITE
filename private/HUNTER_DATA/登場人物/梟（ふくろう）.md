# 梟（ふくろう）

## 略歴・人物像
声 - 鈴木淳 / 山中真尋
[陰獣](../用語集/用語集_ヨークシンシティ編/陰獣.md)の1人。[具現化系](../用語集/用語集_念/具現化系.md)能力者。サングラスの男。
物品の運搬を担当している。[ネオン＝ノストラード](ネオン＝ノストラード.md)の占いの結果を特に警戒し、[地下競売](../用語集/用語集_ヨークシンシティ編/地下競売.md)の金品を移動させた。[地下競売](../用語集/用語集_ヨークシンシティ編/地下競売.md)場を襲撃した[幻影旅団](../用語集/用語集_ヨークシンシティ編/幻影旅団.md)を壊滅させるために、追跡していた。[クラピカ](クラピカ.md)（ウボー捕獲）と旅団のカーチェイスに割り込み、[ノブナガ＝ハザマ](ノブナガ＝ハザマ.md)を捕獲するも、[フェイタン＝ポートオ](フェイタン＝ポートオ.md)たちに返り討ちにされる。[陰獣](../用語集/用語集_ヨークシンシティ編/陰獣.md)の中で1人だけ殺されず、捕らえられ死なない程度に痛めつけられ、[念能力](../用語集/用語集_念/念能力.md)を[クロロ＝ルシルフル](クロロ＝ルシルフル.md)に盗まれた。

## [念能力](../用語集/用語集_念/念能力.md)・特殊能力

### [不思議で便利な大風呂敷（ファンファンクロス）](../念能力/不思議で便利な大風呂敷（ファンファンクロス）.md)
念で創った風呂敷に包んだものを、小さくして閉じ込めることができる具現化能力。車や生物さえも丸ごと包み込み、ポケットに入るサイズに縮小が可能。
