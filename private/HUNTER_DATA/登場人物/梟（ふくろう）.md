# 梟（ふくろう）

## 略歴・人物像
声 - 鈴木淳 / 山中真尋
[陰獣](../用語集/用語集_ヨークシンシティ編/陰獣.md)の1人。[具現化系](../用語集/用語集_念/具現化系.md)能力者。サングラスの男。
物品の運搬を担当している。ネオンの占いの結果を特に警戒し、地下競売の金品を移動させた。地下競売場を襲撃した[幻影旅団](../用語集/用語集_ヨークシンシティ編/幻影旅団.md)を壊滅させるために、追跡していた。[クラピカ](クラピカ.md)（ウボー捕獲）と旅団のカーチェイスに割り込み、ノブナガを捕獲するも、フェイタンたちに返り討ちにされる。[陰獣](../用語集/用語集_ヨークシンシティ編/陰獣.md)の中で1人だけ殺されず、捕らえられ死なない程度に痛めつけられ、[念能力](../用語集/用語集_念/念能力.md)をクロロに盗まれた。

## 念能力・特殊能力

### <span id="不思議で便利な大風呂敷（ファンファンクロス）">不思議で便利な大風呂敷（ファンファンクロス）</span>
念で創った風呂敷に包んだものを、小さくして閉じ込めることができる具現化能力。車や生物さえも丸ごと包み込み、ポケットに入るサイズに縮小が可能。
