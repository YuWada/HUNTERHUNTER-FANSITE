# バッテラ

## 略歴・人物像
声 - 岐部公好 / 梅津秀行
大富豪の老紳士。私財の大半を投じてゲームソフト「[グリードアイランド](../用語集/用語集_グリードアイランド編/グリードアイランド.md)」をサザンピースオークションで全て落札。多数のハンターを雇い、ゲームクリアを試みさせた。その真意は、交通事故により10年以上も昏睡状態に陥ったままの歳の離れた恋人のためにゲーム内アイテム「大天使の息吹」と「魔女の若返り薬」を手に入れることであった。しかし、ゲーム中に恋人が息を引き取ったため、失意のまま依頼を取り消す。指定カードを所持していた[ツェズゲラ](ツェズゲラ.md)とクリアした[ゴン＝フリークス](ゴン＝フリークス.md)たちには違約金350億ジェニーを支払う。
