# 老執事

## 略歴・人物像
声 - 西松和彦 / 相沢まさき
ノストラード家に雇われた者たちの中で一番の最高齢。原作とアニメ第2作では[ダルツォルネ](ダルツォルネ.md)が[クラピカ](クラピカ.md)たちを試したサバイバルテストに巻き込まれて死亡するが、アニメ第1作ではテスト前に避難していった。原作とアニメ第2作では死亡描写が異なり、原作では[ヴェーゼ](ヴェーゼ.md)に盾にされ死亡するが、アニメ第2作では[ヴェーゼ](ヴェーゼ.md)の能力で操作されて恍惚の表情を浮かべながら敵の攻撃を受けて死亡するというコミカルな死亡の仕方をしている（どちらも[ヴェーゼ](ヴェーゼ.md)が原因で死亡している）。
