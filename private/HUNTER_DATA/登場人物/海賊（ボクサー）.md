# 海賊（ボクサー）

## 略歴・人物像
声 - 竹本英史 / 大畑伸太郎
G・Iにゲームキャラクターとして雇われた死刑囚。[放出系](../用語集/用語集_念/放出系.md)能力者。
[レイザー](レイザー.md)のイベントに海賊の一人として関わっており、ボクシングを担当。[モントール](モントール.md)との勝負では拳を瞬間移動させる能力を使い勝利するも、[バリー](バリー.md)との勝負ではインファイトに持ち込まれて瞬間移動能力を使えず、KO負けを喫する。[ツェズゲラ](ツェズゲラ.md)によれば、リング上に刻まれている紋様は[念能力](../用語集/用語集_念/念能力.md)を補佐する「神字」と呼ばれる特殊な文字で、そんなものに頼らないといけないということは地力が低く素の能力は大したことないと言っているようなものだと看破された。
