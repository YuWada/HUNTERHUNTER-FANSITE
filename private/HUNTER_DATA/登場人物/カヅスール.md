# カヅスール

## 略歴・人物像
声 - 高橋広樹（第2期）→加瀬康之（第3期） / 岡林史泰
G・Iプレイヤー。カヅスール組のリーダー。仲間に'''ニック=キュー'''（声 - 不明 / 村上裕哉）と'''スウヘイル'''（声 - 吉野裕行 / 坂熊孝彦）がいる。[ゴン＝フリークス](ゴン＝フリークス.md)たちから「真実の剣」を奪う。[ゴン＝フリークス](ゴン＝フリークス.md)組、[ゴレイヌ](ゴレイヌ.md)、[アスタ](アスタ.md)組、[ヤビビ](ヤビビ.md)組、[ハンゼ](ハンゼ.md)組を呼びかけで集め[レイザー](レイザー.md)のイベントに参加する。真実の剣を奪った時は[ゴン＝フリークス](ゴン＝フリークス.md)たちから警戒されていたが、[モントール](モントール.md)と海賊のボクシング勝負では、海賊が瞬間移動能力を使ったことを見抜けなかったことで修行で力をつけた[キルア＝ゾルディック](キルア＝ゾルディック.md)から戦力外と判断される。その後、[ゲンスルー](ゲンスルー.md)に始末される。
