# 十老頭（じゅうろうとう）

## 略歴・人物像
声 - 小山剛志 / 不明
[マフィアンコミュニティー](../用語集/用語集_ヨークシンシティ編/マフィアンコミュニティー.md)の頭。[マフィアンコミュニティー](../用語集/用語集_ヨークシンシティ編/マフィアンコミュニティー.md)で6大陸10地区を縄張りにしている大組織の長たち。[幻影旅団](../用語集/用語集_ヨークシンシティ編/幻影旅団.md)の抹殺を[シルバ＝ゾルディック](シルバ＝ゾルディック.md)と[ゼノ＝ゾルディック](ゼノ＝ゾルディック.md)に依頼するが、[クロロ＝ルシルフル](クロロ＝ルシルフル.md)から依頼を受けた[イルミ＝ゾルディック](イルミ＝ゾルディック.md)、[マハ＝ゾルディック](マハ＝ゾルディック.md)、[カルト＝ゾルディック](カルト＝ゾルディック.md)によって始末された。
