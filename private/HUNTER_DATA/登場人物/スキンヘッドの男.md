# スキンヘッドの男

## 略歴・人物像
声 - 金子幸伸 / 斉藤次郎
下見市にいた目利き。殺し技の知識が豊富で[ゴン＝フリークス](ゴン＝フリークス.md)たちの品にイチャモンをつける。アニメ第1作では[ゴン＝フリークス](ゴン＝フリークス.md)に殺し技の知識を色々聞かれ困惑していた。アニメ第2作では下見市に登場はせず木造蔵の中身をすり替えて買い取ろうした男性の所で登場し[ゼパイル](ゼパイル.md)と論議する。
