# ニコル

## 略歴・人物像
声 - 石川大介 / 森訓久
受験番号187番。小太りで一見礼儀正しいエリート青年だが、内面は傲慢。自分以外の全ての人間を見下していたが、ハンター試験のレベルにはついて行けず第一次試験最初の脱落者となってしまう。[アモリ](アモリ.md)曰く「新人にしてはいいセンいっていた」らしいが、[トンパ](トンパ.md)の[アモリ](アモリ.md)3兄弟を利用した新人潰し（アニメ第1作では別の方法）によってプライドをズタズタにされてしまい、翌年の第288期ハンター試験には登場していない（OVAでは受験生の中にニコルらしき人物がいる）。他の受験生の情報が入ったノートパソコンを持ち歩いていたが、心身ともにズタボロになっていく中で落としてしまっている。
