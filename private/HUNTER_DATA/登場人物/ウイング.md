# ウイング

## 略歴・人物像
声 - 菊池正美 / 関俊彦 / 遊佐浩二（OVA）
心源[流](../用語集/用語集_念/流.md)拳法師範代。ハンター裏試験試験官。[強化系](../用語集/用語集_念/強化系.md)能力者。
[ズシ](ズシ.md)の師匠。[天空闘技場](../用語集/用語集_天空闘技場編/天空闘技場.md)で“念”の存在を知ったゴンとキルアに“念”の手ほどきをする。普段はノホホンとしていて、寝癖で髪がぼさぼさでいつもシャツが出ており、師匠のビスケや弟子の[ズシ](ズシ.md)にいつも注意されている。ゴンの裏試験の試験官でもある。ビスケには「ひよっこウイング」と呼ばれており、念の覚えは悪かったがその分教える方には向いているとも評されている。ハンター会長選挙に来ていたことから[プロハンター](../用語集/用語集_ハンター試験編/プロハンター.md)である。
