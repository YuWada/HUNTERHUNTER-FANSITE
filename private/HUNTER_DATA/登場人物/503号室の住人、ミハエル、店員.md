# 503号室の住人、ミハエル、店員

## 略歴・人物像
声 - 平川大輔、小山剛志、前川優子 / 二又一成（ミハエル）、荒川美穂（店員）
第288期ハンター試験の協力者。試験会場に入る合言葉の受け答えをする。
それぞれビースカフマロにあるマンションの503号室、同603号室（ミハエル）、駅前の「ディックサクラ」におり、合言葉と指定のカードを渡せば店の一室へ通され、そこが試験会場へのエレベーターになっている。
アニメ第2作では503号室の住人のくだりはカットされている。
