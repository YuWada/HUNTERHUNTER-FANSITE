# モントール

## 略歴・人物像
声 - 遊佐浩二 / 永野広一
[放出系](../用語集/用語集_念/放出系.md)能力者。パンチの際に拳から[念弾](../用語集/用語集_念/念弾.md)を飛ばす能力。[カヅスール](カヅスール.md)の呼びかけで集まり[レイザー](レイザー.md)のイベントに参加する。ボクシング勝負を担当したが、瞬間移動したアッパーを食らい敗北。その後、[ゲンスルー](ゲンスルー.md)に始末される。
