# バラ

## 略歴・人物像
声 - 遊佐浩二 / 浜田賢二
長髪。身長176cm。[ビスケット＝クルーガー（ビスケ）](ビスケット＝クルーガー（ビスケ）.md)と交戦し敗れ、捕縛される。[念の系統](../用語集/用語集_念/念の系統.md)は不明（命の音の系統から、[サブ](サブ.md)とバラとどちらかが、それぞれ[操作系](../用語集/用語集_念/操作系.md)と[放出系](../用語集/用語集_念/放出系.md)の能力者であると考えられる）。少女姿の[ビスケット＝クルーガー（ビスケ）](ビスケット＝クルーガー（ビスケ）.md)の攻撃に耐えたこと、真の姿で顔面をまともに殴ったにもかかわらず生きていたことから、[ビスケット＝クルーガー（ビスケ）](ビスケット＝クルーガー（ビスケ）.md)は二度「強い」と評していた。瀕死の状態になっていたが、「大天使の息吹」で治療された。3人の中では比較的思慮が浅いようで、やや短絡的な発言が目立つ。
