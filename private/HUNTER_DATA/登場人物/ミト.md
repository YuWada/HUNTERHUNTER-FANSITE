# ミト

## 略歴・人物像
声 - 木村亜希子 / 潘恵子 / 岡村明美（パイロット版）
[ゴン＝フリークス](ゴン＝フリークス.md)の育ての親。9月7日生まれ。[ジン＝フリークス](ジン＝フリークス.md)の従妹で、[ゴン＝フリークス](ゴン＝フリークス.md)の叔従母（いとこおば）。気が強いが根は優しく、実の母親同然に[ゴン＝フリークス](ゴン＝フリークス.md)を育てた。
祖母（[ゴンの曾祖母](ゴンの曾祖母.md)）と共に[くじら島](../用語集/用語集_ハンター試験編/くじら島.md)で小さな酒屋を営む。裁判で[ジン＝フリークス](ジン＝フリークス.md)から親権を奪い[ゴン＝フリークス](ゴン＝フリークス.md)を女手ひとつで育てた。幼少時は島の子供が少なかったこともあり、[ジン＝フリークス](ジン＝フリークス.md)にかまって貰いたがっていた。[ゴン＝フリークス](ゴン＝フリークス.md)がハンターになることは当初から反対しており、[ゴン＝フリークス](ゴン＝フリークス.md)が試験に合格して里帰りしたのちも[ゴン＝フリークス](ゴン＝フリークス.md)と暮らしたいとの思いは持ち続けていたが、[ゴン＝フリークス](ゴン＝フリークス.md)が自分を実の母親同然に慕っていることを知りそれまで隠していた[ジン＝フリークス](ジン＝フリークス.md)の手がかりを与えた。[ゴン＝フリークス](ゴン＝フリークス.md)の里帰りの際には、同行していた[キルア＝ゾルディック](キルア＝ゾルディック.md)も快く迎え入れており、[キルア＝ゾルディック](キルア＝ゾルディック.md)からも理想の母親像として憧れられている。殺生を嫌う。
